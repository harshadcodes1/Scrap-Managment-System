# Scrap Management System

A web-based Scrap Management System developed using PHP and MySQL to efficiently manage scrap materials, users, departments, storage locations, Z-forms, and scrap sales. The system provides an admin dashboard for managing records, approving or rejecting Z-forms, and generating PDF/Excel reports.

## Technologies Used

* PHP
* MySQL
* HTML5
* CSS3
* Bootstrap
* JavaScript
* jQuery
* TCPDF

## Key Features

* User and department management
* Scrap material management
* Storage location management
* Z-form creation and management
* Scrap sale entry and vendor management
* Admin approval/rejection system
* CRUD operations
* PDF report generation
* Excel data export
* Login and logout functionality
